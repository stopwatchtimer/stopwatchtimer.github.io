# Stopwatch & Timer

A free online stopwatch with lap times, plus a countdown timer, interval timer and world clock. No download, no sign-up.

Free online tool site built for GitHub Pages. Static HTML, CSS and JavaScript only — no build step, no server, no tracking. Open `index.html` to start.

- Main tool: Online Stopwatch (`tools/stopwatch.html`)
- 4 tools, 20 guides, 20 images.
